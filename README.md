# Automobile Picobello

A live business website built in 2024 for **Automobile Picobello**, an automotive business in Speyer, Germany.

This project was created as a practical learning project for a real business and is currently used to present the company, its services and contact information online.

## Live Website

https://automobile-picobello.de

## Features

- Responsive business website
- Company introduction and service overview
- Vehicle sales information
- Vehicle purchase / trade-in information
- Financing information
- Opening hours and contact details
- Link to current vehicle listings on mobile.de
- Impressum page

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Project Background

The goal was to create a simple, clear and practical website for a real automotive business while strengthening my frontend development skills through a real-world use case.
